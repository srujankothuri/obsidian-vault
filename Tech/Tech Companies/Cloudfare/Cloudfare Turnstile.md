**Cloudflare Turnstile is a bot check for websites.** It serves the same purpose as a CAPTCHA. It helps a site decide whether a visitor is a real person or an automated bot, usually without asking them to solve an image puzzle.

Say you build a **sign-up form**. When someone opens it, Turnstile runs small checks in their browser. Most visitors can continue without doing anything. Sometimes they’ll see a **“Verify you are human”** checkbox. Your site can use the result to decide whether to accept the signup.

### Cloudflare Turnstile confirms web visitors are real and blocks unwanted bots without slowing down web experiences for real users. It's a simple snippet of free code that eliminates CAPTCHAs. With Turnstile, you can deliver better experiences and strengthen privacy for all users.
